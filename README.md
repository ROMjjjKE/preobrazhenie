# Салон маникюра «Искусство Преображения», Минск

Две страницы, чистый HTML, CSS и JS. Метаданные и шапка собираются `build.py`.

## Страницы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Главная: салон, конструктор формы и цвета, услуги, визит, вопросы, адрес и запись |
| `politika.html` | Политика обработки данных |

## Фотографии

В этот раз использованы **реальные фото салона** из присланных файлов (два кадра интерьера).
Из каждого срезана нижняя полоса с водяным знаком, кадры обрезаны под нужные пропорции
и слегка подшарплены. Никаких сгенерированных интерьеров: сайт показывает то, что есть.

Нужны дополнительные кадры, чтобы блок «Салон» стал сильнее:
1. работа мастера крупным планом (руки, кисть, инструмент);
2. готовый маникюр на модели (2–3 ракурса, можно телефоном при дневном свете);
3. общий вид зала от входа, чтобы было понятно, как выглядит пространство;
4. фасад или входная дверь с вывеской, для блока адреса.

Пропорции: герой 20:24, большой кадр салона 20:24, малый 4:5, блок «вопросы» 4:3.

## Интерактив

Конструктор маникюра: форма (овал, миндаль, квадрат, стилет), длина (короткая, средняя,
длинная) и покрытие (нюд, молочный, тёмная зелень, френч). Ноготь перерисовывается
в SVG: путь считается по выбранной форме и длине, френч показывается белой полосой через
clipPath. Кнопка «Записаться с этим вариантом» переносит выбор в комментарий заявки.

Оттенки на экране условные, об этом прямо написано в блоке: точный цвет выбирается по выкрасам.

## Что уточнить у салона

1. **Цены.** В брифе их нет, поэтому вместо прайса объяснено, как узнать стоимость,
   и предложен WhatsApp. Если пришлёте прайс, блок «Услуги» станет таблицей с ценами.
2. **Часы работы.** Сейчас «по записи». Если есть график, его нужно добавить в блок адреса.
3. **Список услуг.** Взят типовой для салона маникюра: маникюр, гель-лак, укрепление,
   наращивание, педикюр, дизайн, снятие, уход. Проверьте, что всё это делаете, и уберите лишнее.
4. **Реквизиты.** В политике указан оператор без УНП и юридического адреса.
5. **Домен.** Сейчас `https://romjjjke.github.io/preobrazhenie/`. Свой домен: Settings →
   Pages → Custom domain, файл `CNAME` и запись у регистратора.

## Проверки

- нет горизонтального скролла на 1440, 1180, 1080, 900, 768, 390 и 360 px
- контраст текста от 5.59:1, кнопки и элементы конструктора от 10.83:1
- конструктор: путь ногтя, цвет, френч и подпись меняются синхронно, выбор переносится в форму
- форма: пустая не уходит, ошибки показываются, заполненная собирает сообщение в WhatsApp
- водяной знак kufar срезан вместе с нижней полосой кадров (проверено по пикселям)
